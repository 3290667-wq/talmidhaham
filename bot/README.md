# חברותא דיגיטלית - מדריך הפעלה

בוט שמלווה כל אחד מחברי הקבוצה בדרך לתלמיד חכם: משימה יומית לפי התכנית שבחר, בחנים על מה שלמד, חזרה מרווחת חכמה, ומענה על שאלות בסוגיה - עם מקורות אמיתיים בלבד.

**עיקרון:** הבוט כותב מה ללמוד היום, אתה לומד מהספרים שלך, והוא בוחן אותך. מי שרוצה יכול לבקש "טקסט" ולקבל את טקסט הלימוד עצמו + קישור לספריא (גם לכל מקור חופשי: "טקסט ברכות ה").

**בקבוצה:** לכל משתתף תכנית, בחנים, חזרות ורצף משלו. הבוט שותק על פטפוט רגיל ומגיב רק כשפונים אליו.

---

## שלב א: מה צריך (פעם אחת)

1. **Node.js 18+** (בשרת הזה: v23.11.1 דרך nvm)
2. **מפתח Gemini** (המוח של הבחנים) מ- https://aistudio.google.com/apikey
3. בתיקיית `bot`:
   ```
   cp .env.example .env
   ```
   ולמלא ב-`.env` את `GEMINI_API_KEY`. אין תלויות npm - הבוט רץ על Node לבדו.

## שלב ב: הפעלה במצב בדיקה (בלי ווצאפ)

```
node src/index.js --console
```

תיפתח שיחה עם הבוט בתוך החלון. כתוב "הרשמה" והוא יתחיל את שאלון הפתיחה.

## שלב ג: חיבור לקבוצת ווצאפ

הבוט מחובר לקבוצה דרך **whatsapp-claude-bridge** (Evolution API) שכבר רץ בשרת.
ל-instance של Evolution יש webhook יחיד והברידג' כבר מחזיק בו, לכן הברידג'
מזהה את הקבוצה ומעביר לכאן, והבוט שולח תשובות דרך ה-API שלו.

```
ווצאפ → Evolution API → claude-bridge (3002) → talmid-bot (3005)
                              ↑ /send-text ←────────┘
```

**מה מגדירים:**

ב-`.env` של הבוט:
```
TALMID_GROUP_ID=120363409417834977@g.us    # קבוצת "כתר תורה"
BRIDGE_URL=http://localhost:3002
PORT=3005
```

ב-`.env` של הברידג' (`/home/amichai/whatsapp-claude-bridge`):
```
TALMID_GROUP_ID=120363409417834977@g.us
TALMID_BOT_URL=http://localhost:3005
```

אחרי שינוי ב-`.env` של הברידג' או ב-`src/whatsapp/client.ts` צריך:
```
cd /home/amichai/whatsapp-claude-bridge && npm run build && pm2 restart claude-bridge
```

**הרצה:**
```
pm2 start src/index.js --name talmid-bot --cwd /home/amichai/talmidhaham/bot
pm2 logs talmid-bot
```

### למצוא מזהה של קבוצה אחרת
```
curl -H "apikey: $EVOLUTION_API_KEY" \
  "http://localhost:8080/group/fetchAllGroups/amichai?getParticipants=false" | jq '.[] | {id, subject}'
```

## פקודות הבוט (בקבוצה)

| פקודה | מה היא עושה |
|---|---|
| `הרשמה` | פותח את שאלון הפתיחה (מסלולים, קצב, שעה, שבת) |
| `למדתי` | סיימת ללמוד? בוחן קצר |
| `חזרה` | הפעלת חזרות שהגיע זמנן |
| `מצב` | סיכום התקדמות ורצף |
| `היום` | מה המשימה של היום |
| `שאלה ...` | שאלה על הסוגיה הנוכחית |
| `דלג` | "יום חסד" - התקדמות בלוח בלי בוחן |
| `הגדרות` | הצגת ההגדרות הנוכחיות |
| `שנה שעה 7` | שעת המשימה היומית |
| `שנה שבת` | מעבר בין לימוד בשבת למנוחה |
| `שנה תכנית` | בניית תכנית מחדש. אם אתה באמצע מסכת - הבוט מזהיר ומבקש אישור |
| `שנה תכנית בכל זאת` | עקיפת האזהרה |
| `עזרה` | תפריט מלא של כל היכולות |

כל הודעה אחרת בקבוצה - הבוט שותק.

### כפתורים

הודעות מרכזיות (משימת הבוקר, תזכורת הערב, סיום בוחן, סיום חזרות) מגיעות עם
כפתורי פעולה מהירה - ביניהם **❓ עזרה**. לחיצה על כפתור זהה להקלדת הפקודה:
ה-`id` של הכפתור הוא הפקודה עצמה, והברידג' מחלץ אותו מהודעת התגובה
(`interactiveResponseMessage` / `buttonsResponseMessage` / `templateButtonReplyMessage`).
ווצאפ מציג עד 3 כפתורים בהודעה. אם לקוח לא תומך בכפתורים - הבוט נופל חזרה לטקסט רגיל.

### מה אפשר ללמוד

ארבעה מסלולים מובנים (גמרא · משנה · שולחן ערוך לפי חלק: אורח חיים / יורה דעה / אבן העזר / חושן משפט · תנ"ך) ובנוסף
**מסלול 5 - כל ספר שיש בספריא**: כותבים את שם הספר בעברית והבוט פותר אותו
מול ספריא (`/api/name/`), בונה ממנו לוח לימוד (`/api/shape/`) ובוחן עליו כרגיל.
עובד גם על ספרים פשוטים (מסילת ישרים, שמונה פרקים) וגם על מורכבים
(חובות הלבבות עם שערים, תניא, משנה תורה). שגיאת כתיב מקבלת הצעות תיקון.

**קצב הגמרא ללא הגבלה** - אפשר `1` (עמוד), `דף`, `3 דפים`, `7` (עמודים).
התקרה היחידה היא אורך המסכת.

## מודל ה-AI

ברירת המחדל: `gemini-3.6-flash` - מהיר וזול, מספיק לחיבור שאלות ולמשוב.
לשדרוג לאיכות גבוהה יותר: `GEMINI_MODEL=gemini-3.1-pro-preview`.
רשימת המודלים הזמינים למפתח שלך:
```
curl -s "https://generativelanguage.googleapis.com/v1beta/models?key=$GEMINI_API_KEY" | jq -r '.models[].name'
```

## כללי האמינות (מובנים בקוד)

- כל תשובה ובוחן נבנים אך ורק מהטקסט שנשלף מספריא
- כל טענה מלווה בציון מקור
- אין מקור? הבוט אומר "לא מצאתי - שאל רב"
- שאלות הלכה למעשה מופנות תמיד לרב
- הבוט הוא עזר לחזרה - לא תחליף לרב, לשיעור או לחברותא חיה

## תקלות נפוצות

- **"חסר מפתח GEMINI_API_KEY"** - לא נוצר `.env` או שהמפתח לא הודבק בו
- **"אין הרשאה ל-Gemini API"** (403) - ה-Generative Language API לא מופעל בפרויקט
  של המפתח. להפעיל ב-Google Cloud Console או לייצר מפתח חדש ב-AI Studio.
- **הבוט לא מגיב בקבוצה** - לוודא ש-`TALMID_GROUP_ID` זהה בשני קובצי ה-`.env`,
  שהברידג' עבר `npm run build` + `pm2 restart claude-bridge`, ו-`curl localhost:3005/health` מחזיר `ok`
- **הבוט מגיב אבל ההודעה לא מגיעה** - `pm2 logs talmid-bot` יראה `bridge send failed`
- **כפתורים מגיעים כטקסט רגיל** - לקוח ווצאפ ישן. הבוט נופל חזרה לטקסט אוטומטית
  והפקודות עדיין עובדות בהקלדה.
- **ספר חופשי לא נמצא** - הבוט מציע השלמות מספריא. אם אין - השם לא קיים שם.
- **שגיאת ספריא** - בעיית אינטרנט רגעית, לנסות שוב
- **להתחיל הכל מחדש** - למחוק את `data/store.json` ולהריץ `pm2 restart talmid-bot`
