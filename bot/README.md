# חברותא דיגיטלית - מדריך הפעלה

בוט אישי שמלווה אותך בדרך לתלמיד חכם: משימה יומית לפי התכנית שבחרת, בחנים על מה שלמדת, חזרה מרווחת חכמה, ומענה על שאלות בסוגיה - עם מקורות אמיתיים בלבד.

**עיקרון:** הבוט לא שולח טקסט ללימוד. הוא כותב מה ללמוד היום, אתה לומד מהספרים שלך, והוא בוחן אותך.

---

## שלב א: מה צריך להתקין (פעם אחת)

1. **Node.js** - אם עוד לא מותקן: להוריד מ- https://nodejs.org (גרסת LTS) ולהתקין בקליק.
2. **מפתח Claude AI** (המוח של הבחנים):
   - נכנסים ל- https://console.anthropic.com ונרשמים
   - יוצרים API Key ומעתיקים אותו
3. בתיקיית `bot` - להעתיק את הקובץ `.env.example` לקובץ חדש בשם `.env`, ולהדביק בו את המפתח:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

## שלב ב: הפעלה במצב בדיקה (בלי ווצאפ)

לפתוח טרמינל בתיקיית `bot` ולהריץ:

```
node src/index.js --console
```

תיפתח שיחה עם הבוט בתוך החלון. כתוב "שלום" והוא יתחיל את שאלון הפתיחה.

פקודות הבוט: `למדתי` · `חזרה` · `מצב` · `היום` · `שאלה ...` · `דלג` · `שנה תכנית` · `עזרה`

## שלב ג: חיבור לווצאפ (Green API - עובד תוך שעה)

1. נכנסים ל- https://green-api.com ונרשמים (יש חבילת חינם למתחילים, ~30 ש"ח לחודש בחבילה קבועה).
2. יוצרים Instance וסורקים קוד QR עם הווצאפ (מומלץ מספר נפרד/ישן, לא המספר האישי - ליתר ביטחון).
3. מעתיקים ל-`.env`:
   ```
   GREENAPI_ID_INSTANCE=1234567890
   GREENAPI_API_TOKEN=abc123...
   USER_PHONE=972501234567
   ```
   (`USER_PHONE` = המספר שלך, שממנו תכתוב לבוט)
4. מריצים:
   ```
   node src/index.js
   ```
5. שולחים "שלום" בווצאפ למספר של הבוט - והשאלון מתחיל.

## שלב ד: שהבוט ירוץ תמיד (ענן)

כדי שהודעת הבוקר תגיע גם כשהמחשב כבוי, מעלים את התיקייה לשרת קטן בענן
(Railway / Fly.io / render.com, ~20-25 ש"ח לחודש). זה השלב היחיד שכדאי לעשות
יחד עם Claude Code - פשוט לבקש: "העלה את הבוט ל-Railway".

## מה יש בפנים (למתעניינים)

| קובץ | תפקיד |
|---|---|
| `src/index.js` | נקודת הכניסה - בוחר ערוץ (טרמינל/ווצאפ) ומפעיל הכל |
| `src/conversation.js` | מוח השיחה: שאלון פתיחה, בחנים, חזרות, פקודות |
| `src/curriculum.js` | לוחות הש"ס, המשנה, קיצור שו"ע והתנ"ך |
| `src/sefaria.js` | שליפת הטקסט האמיתי מספריא (לשימוש פנימי בלבד) |
| `src/ai.js` | Claude AI: חיבור שאלות, בדיקת תשובות, מענה מעוגן במקורות |
| `src/fsrs.js` | מנוע החזרה המרווחת (1, 3, 7, 14, 30, 90, 180, 365 ימים) |
| `src/scheduler.js` | הודעת הבוקר ותזכורת הערב |
| `data/store.json` | כל ההתקדמות שלך (נוצר אוטומטית; לגבות מדי פעם) |

## כללי האמינות (מובנים בקוד)

- כל תשובה ובוחן נבנים אך ורק מהטקסט שנשלף מספריא
- כל טענה מלווה בציון מקור
- אין מקור? הבוט אומר "לא מצאתי - שאל רב"
- שאלות הלכה למעשה מופנות תמיד לרב
- הבוט הוא עזר לחזרה - לא תחליף לרב, לשיעור או לחברותא חיה

## תקלות נפוצות

- **"חסר מפתח ANTHROPIC_API_KEY"** - לא נוצר קובץ `.env` או שהמפתח לא הודבק בו
- **הבוט לא עונה בווצאפ** - לבדוק שה-Instance ב-Green API במצב Authorized (QR נסרק), ושה-`USER_PHONE` נכון (בלי + ובלי מקפים)
- **שגיאת ספריא** - בעיית אינטרנט רגעית, לנסות שוב
- **להתחיל הכל מחדש** - למחוק את `data/store.json` ולהריץ שוב
